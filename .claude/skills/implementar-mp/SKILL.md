Implemente o trabalho descrito pelo usuário na spec ou nos tickets.

Use /tdd-mp sempre que possível, nas costuras (seams) acordadas previamente.

Rode a verificação de tipos regularmente, arquivos de teste isolados regularmente, e a suíte de testes completa uma vez ao final.

Quando terminar, use /revisar-codigo-mp para revisar o trabalho.

Faça o commit do seu trabalho na branch atual.
